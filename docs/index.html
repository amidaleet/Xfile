Xfile — bash task runner (Makefile alternative)

Simple bash template for repository scripts: tasks, args, help and shell completion. A Makefile alternative, not a YAML Taskfile.

Why run bash → Makefile → bash, if just bash is possible?

Install into a repo:

curl -fsSL "https://raw.githubusercontent.com/amidaleet/Xfile/7.1.1/Xfile_source/setup.sh" -o setup.sh
chmod +x setup.sh
XFILE_REF='7.1.1' ./setup.sh
rm -f setup.sh
